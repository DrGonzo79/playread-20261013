# Phased build prompts

## Phase 1 — paid concierge proof

> Build a secure analyst checklist around one real Unity or Unreal prototype. Store only metadata until NDA, retention, and deletion controls are approved. Capture artifact-level citations for every finding. Measure reviewer time, publisher decision changes, and willingness to pay $4,500.

## Phase 2 — ephemeral snapshot

> Add an isolated worker that clones or opens a build with least-privilege temporary credentials, detects engine/version/dependency structure, inventories asset licenses, runs bounded smoke tests, and deletes all customer files with a signed receipt. Keep every automated claim reviewable and never infer legal ownership.

## Phase 3 — reviewer evidence room

> Add tenant authentication, immutable evidence artifacts, assessment versions, human overrides, role-based access, audit logs, retention policies, and signed memo export. Instrument latency, ingestion failures, overrides, false positives, deletion proof, and security incidents.

## Phase 4 — benchmark moat

> Only after 50+ completed memos with permission, create anonymized engine/stage benchmarks and link initial findings to milestone and launch outcomes. Test whether benchmarks improve decisions; prevent small-cohort re-identification and allow complete customer exclusion.
